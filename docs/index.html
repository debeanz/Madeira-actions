Windows games. On your iPhone.

Madeira runs PC games inside one iOS app. Wine stands in for Windows, FEX translates the game's x86 code to ARM64 as it runs, and DXMT turns Direct3D into Metal. No jailbreak: you sideload it and let a debugger switch on JIT.

How it works

From a Windows .exe to the iPhone's GPU

All of it runs inside the one app. Even Wine's server is a thread rather than a separate process, because an iOS app can't start processes of its own.

Questions

Good to know

How can an iPhone run Windows games at all?

Three translators work together inside one app. Wine answers the game's calls to Windows, FEX converts its x86 code to ARM64 while it runs, and DXMT turns its Direct3D graphics into Metal, which the iPhone's GPU draws. Even Wine's server runs as a thread inside the app.

Does it need a jailbreak?

No. It's an ordinary sideloaded app. The one special requirement is JIT, which StikDebug provides by attaching as a debugger.

Why JIT, and why isn't it on the App Store?

FEX writes new ARM64 code while the game runs, and iOS only lets an app do that while a debugger is attached. App Store apps can't have one, so Madeira is sideloaded and StikDebug attaches for it.

Which games work?

The compatibility list has what players have reported. Direct3D 11 games are the best bet — Unity games like Untitled Goose Game run, and so does Undertale, a 32-bit GameMaker game.

What about DirectX 12, OpenGL and Vulkan?

Madeira draws with Direct3D 11 and Direct3D 9. Many DirectX 12 games also have a DirectX 11 mode, and Madeira starts them in it automatically. Games that only use DirectX 12, OpenGL or Vulkan don't run yet.

How fast does it run?

It depends on the game. Untitled Goose Game holds 60 fps on an iPhone 15 Pro Max, while bigger 3D games are limited by the iPhone's GPU. Every game has its own resolution and frame-rate cap, and DirectX 11 games can use MetalFX upscaling for a sharper picture.

Can I play with a controller?

Yes. Bluetooth controllers reach games as an Xbox controller, in 64-bit and 32-bit games alike, and for games without controller support each button can send a key instead. No controller? Use the on-screen Xbox pad, or a keyboard layout you arrange yourself.

Do I need a copy of Windows?

No. Wine stands in for Windows, so nothing from Microsoft is installed. Madeira ships no games either — you copy in games you own.

Where do my saves go?

Inside the app, in its Wine prefix — the same place a Windows PC would keep them. They survive reinstalling Madeira.

Why does my iPhone get hot?

A PC game works the phone hard. After a few minutes of a heavy game it warms up, and iOS slows the chip down to cool it, which can lower the frame rate. A lower resolution or a 30 fps cap keeps it cooler.

A game crashed. What now?

Madeira offers to save the log or report the game right away. A report with its log attached is how games get fixed — and quitting and reopening Madeira before the next game avoids leftovers from the crash.

What does a report share?

Reports are public: your rating and notes, the device model, iOS and Madeira versions, and the game's settings. The log goes only to the developer. It contains file paths from your phone, so it's never shown here.
