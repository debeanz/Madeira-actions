Windows games. On your iPhone.

Madeira runs PC games inside one iOS app. Wine stands in for Windows, FEX translates the game's x86 code to ARM64 as it runs, and DXMT turns Direct3D into Metal. No jailbreak: you sideload it and let a debugger switch on JIT.

How it works

From a Windows .exe to the iPhone's GPU

All of it runs inside the one app. Even Wine's server is a thread rather than a separate process, because an iOS app can't start processes of its own.

Game

Your .exe

The Windows build you already own — 64-bit or 32-bit.

Windows

Wine

Stands in for Windows, built for ARM64EC: files, windows, input and sound.

CPU

FEX

Translates the game's x86 code to ARM64 as it runs, so it executes natively.

Graphics

DXMT

Turns Direct3D 11 into Metal — and Direct3D 9, for 32-bit games.

Device

Your iPhone

Metal draws the frame. Touch, controllers and audio flow back to the game.

Install

Four steps to your first game

Games need JIT to run at speed, and iOS only allows it while a debugger is attached — so Madeira can't be on the App Store. You sideload it.

Get the app

Every change is built by GitHub Actions. Download the newest Madeira-0.1.x artifact from the repository's Actions tab while signed in to GitHub.

Sideload it

Install the IPA with your Apple ID. A free account works, but it expires after 7 days — reinstalling keeps your games and saves.

Turn on JIT

Install StikDebug. When you start a game, Madeira asks it to attach.

Add a game

In the Files app, put each game in its own folder on the C: drive — Madeira › wine › drive_c. It shows up in the Games tab.

  • It's a research project. Plenty of games run; some run slowly or not at all. Check the compatibility list first.
  • Direct3D only. Games that need OpenGL or Vulkan don't run yet.
  • Bring your own games. Madeira ships no games and no copy of Windows — you copy in games you own.
Questions

Good to know

Does it need a jailbreak?

No. It's an ordinary sideloaded app. The one special requirement is JIT, which StikDebug provides by attaching as a debugger.

Which games work?

The compatibility list has what players have reported. Direct3D 11 games are the best bet — Unity games like Untitled Goose Game run, and so does Undertale, a 32-bit GameMaker game.

Where do my saves go?

Inside the app, in its Wine prefix — the same place a Windows PC would keep them. They survive reinstalling Madeira.

A game crashed. What now?

Madeira offers to save the log or report the game right away. A report with its log attached is how games get fixed — and quitting and reopening Madeira before the next game avoids leftovers from the crash.

What does a report share?

Reports are public: your rating and notes, the device model, iOS and Madeira versions, and the game's settings. The log goes only to the developer. It contains file paths from your phone, so it's never shown here.
